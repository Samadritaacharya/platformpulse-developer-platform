# Deploy PlatformPulse on Streamlit Community Cloud

1. Sign in to Streamlit Community Cloud with GitHub.
2. Select **Create app**.
3. Choose repository `Samadritaacharya/platformpulse-developer-platform`.
4. Select branch `main`.
5. Set the entry point to `app.py`.
6. Deploy without secrets; the application uses synthetic local data only.
7. Add the resulting public URL to the repository **About** section and README.

## Pre-share checklist

- GitHub Actions is green.
- The app opens without authentication.
- All seven navigation views render.
- The Golden Path Generator downloads a valid ZIP.
- The repository and app clearly label data as synthetic.
- No API keys, tokens or employer information are present.
