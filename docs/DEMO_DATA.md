# Demo Data Catalogue

All datasets are synthetic and contain no employer, client or personal data.

| File | Purpose |
|---|---|
| `survey_results.csv` | developer discovery evidence and journey friction |
| `services.csv` | service ownership, documentation, SLO and incident catalogue |
| `pipeline_metrics.csv` | CI/CD, lead-time, recovery and support signals |
| `feedback.csv` | product opportunities and prioritisation inputs |
| `ab_test_events.csv` | event-level Control/Treatment experiment records |
| `ai_use_cases.csv` | AI use-case inventory and governance controls |

The repository uses a stable synthetic as-of date derived from the newest committed service or pipeline record. This prevents the portfolio demo from becoming misleadingly stale as calendar time passes.
