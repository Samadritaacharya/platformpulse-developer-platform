# Metrics Dictionary

| Metric | Product question | Prototype definition |
|---|---|---|
| Developer Experience Score | Is the developer journey improving? | Composite of friction, time lost and recurrence |
| Time to first deployment | How quickly can a new engineer reach value? | Median time lost at the deploy stage |
| Golden-path adoption | Are supported workflows being used? | Services marked as created through the golden path |
| Pipeline success rate | Is the delivery path reliable? | Percentage of latest service pipelines passing |
| Pipeline duration | Is feedback fast enough? | Median CI duration |
| Ownership coverage | Can people find an accountable team? | Percentage of services with a named owner |
| Documentation coverage | Is operating knowledge discoverable? | Percentage of services with documentation |
| SLO coverage | Are reliability expectations explicit? | Percentage of services with an SLO |
| Deployment frequency | Are teams delivering regularly? | Sum of deployments normalised to a week |
| Change lead time | How quickly does work reach users? | Median hours from change to delivery |
| Change-failure rate | How often do changes introduce failure? | Percentage of changes associated with a failure signal |
| MTTR | How quickly is service restored? | Median recovery time in minutes |
| Support demand | Is repeated friction being removed? | Sum of platform-related support requests |

These are independent product hypotheses for a portfolio prototype. They are not presented as any employer's internal metrics.
